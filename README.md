# playground-apps

개인 실습용 예제 앱 모음입니다. 폴더마다 독립된 작은 프로젝트이며, 각 폴더의 README에 실행 방법과 정책이 있습니다.

| 폴더 | 내용 | 언어 |
|---|---|---|
| `web-shop/` | 주문 조회·취소, 배송 조회, 알림 | TypeScript (React + Express) |
| `quiz-game/` | 브라우저 퀴즈 게임 (점수·콤보·기록 저장) | JavaScript |
| `report-cli/` | 이벤트 CSV 사용자별 요약 CLI | Python |
| `board-api/` | 익명 게시판 API | Java (Spring Boot) |
| `jobqueue-go/` | 작업 큐 워커 | Go |
