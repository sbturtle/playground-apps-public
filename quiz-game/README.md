# quiz-game

브라우저에서 바로 실행하는 4지선다 퀴즈 게임입니다. 빌드 없이 정적 파일로 동작합니다.

```bash
npx serve quiz-game
```

## 규칙

- 문제마다 15초 제한, 목숨 3개. 틀리거나 시간이 지나면 목숨이 1개 줄어듭니다.
- 난이도: 쉬움(20초)·보통(15초)·어려음(10초). 주소에 `?level=easy`처럼 붙여 고르며, 기본은 보통입니다.
- 일시정지: 문제를 푸는 중에 멈췄다가 이어서 풀 수 있습니다. 멈춘 동안에는 시간이 흐르지 않습니다.
- 점수: 정답 100점 + 남은 시간 1초당 5점, 콤보 3부터 보너스.
- 경험치(XP): 정답 1개당 10, 최대 콤보 5 이상이면 보너스 30.
- 최고 점수·누적 XP·최근 50판 기록을 브라우저 localStorage(`quiz-game:progress`)에 저장합니다. 저장 형식이 바뀌어도 기존 기록은 유지되어야 합니다.
